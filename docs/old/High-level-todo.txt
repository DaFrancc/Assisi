High-level todo
Updated 2026-08-06

Two tiers. The first is what essentially every game needs, so it gets built
whether or not a specific game asks for it. The second is everything else —
real work, but wait until a game actually needs it. Nothing is listed twice.


=====================================================================
TIER 1 — every game needs these
=====================================================================

Roughly dependency-ordered, not a strict sequence.

Audio (mixer, 3D spatialization, buses, streaming music; occlusion later)
Animation system (skeletal, blending, state machine; root motion optional)
GUI system (HUD + menus; includes real text/font rendering outside ImGui)
Physics gameplay surface — the part Jolt is wired for but doesn't expose yet:
    Scene queries: raycast, shapecast, overlap
    Triggers / sensors and collision events surfaced to ECS
    Character controller (Jolt CharacterVirtual)
Shadows (lighting L1 — directional CSM; plan already written)
Post processing / HDR pipeline (lighting L2 — RGBA16F, tonemap, bloom, exposure)
Transparency and alpha modes (cutout, blended; particles and foliage both need
    it, and lighting L3 is blocked on it)
Particles / VFX (emitters, ribbons, decals)
Sky / atmosphere (there is no skybox at all today)
Save games / gameplay persistence (level serialization is not a save file)
Gamepad support (ActionMap is keyboard + mouse only) + input remapping
Settings menu and options persistence
Convert assets to binaries (potentially with encryption) → cook/pak, then
    packaging: installer, patching
Loading screen, plus a startup and load-time budget to hold it to


=====================================================================
TIER 2 — build when a game needs it
=====================================================================

In no specific order.

Scale and streaming

World chunking
LOD system

World content

Terrain / heightfield (+ layered materials)
Foliage / instanced scatter
Navmesh + pathfinding, and whatever AI layer sits on it
Cinematics / sequencer (timeline, keyframed tracks, camera cuts)
Video playback

Gameplay systems

Scripting or behaviour graphs (blueprints today compose data, not logic)
Constraints / joints
Collision layers and filtering as authored data
Vehicles
Localization (string tables, font coverage, runtime language switch)

Rendering

Volumetric fog
Render graph or pass scheduler, and multithreaded command recording
Screenshot + offline high-res capture

Platform

Multi-monitor / fullscreen / display-mode handling in options
Per-device input profiles, dead zones

Tooling and editor

Terrain / foliage painting tools
Particle editor
Asset hot reload (textures, materials, shaders) without a restart
Shader compilation pipeline: variants, caching, warm-up
Profiler surfacing in-editor beyond Chiara's dump (Perfetto pass still owed)
In-game console / dev commands / cvars

Shipping

Crash reporting and minidumps
Log shipping / opt-in telemetry

Engineering health

CI is deliberately absent — the substitute is a documented local verify command
-Werror is off everywhere; the tree has warnings today
Soak / stress tests for the job system and async streaming under load
MemorySanitizer coverage for uninitialized reads (needs an instrumented dep tree)
Determinism harness (fixed-step replay), which networking will want anyway
Public API docs and sample projects for the template
