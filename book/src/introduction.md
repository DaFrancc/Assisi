# Introduction

Welcome to **The Assisi Book**. This book teaches you how to make a game with
Assisi, a C++ game engine for Windows and Linux.

> **Assisi is still being built.** Everything in this book describes the engine
> as of **September 18, 2026**, and any of it may change: names, file formats,
> the editor, the workflow. Some features are incomplete, and the book says so
> where it matters, but expect rough edges everywhere. If the book and the
> engine disagree, the engine is right; please
> [open an issue](https://github.com/DaFrancc/Assisi/issues) so the book can be
> fixed.

You don't need to know how the engine works inside to use it. You write your
game's logic in C++, build your levels in the editor, and the engine handles
windows, rendering, physics, saving and loading, and networking.

## Who this book is for

This book is for people who know some C++ and want to make a game with Assisi.
It doesn't assume you've used a game engine before. If you have, you'll be able
to skim quickly: every chapter starts with the short version and explains
afterwards.

## What you'll learn

By the end of the book you will be able to:

- build the engine and open the editor,
- write *systems*: the functions that make things happen in your game,
- define your own *components*: the data your game objects carry,
- read the keyboard and mouse, use physics, and build levels,
- package your game so someone else can play it.

## How the book is organized

- **Getting started** gets the engine built and shows you around the repository.
- **Making a game** covers the day-to-day work: entities, components, systems,
  input, physics, levels and the editor.
- **Shipping** covers settings, build types and packaging a game for players.
- **Going further** covers multiplayer and common problems.

You can read it front to back, or jump straight to the chapter you need.

## Getting help

If something in this book is wrong or unclear, or you're stuck, open an issue on
the [issue tracker](https://github.com/DaFrancc/Assisi/issues). Every page also
has an edit button in the top-right corner if you'd like to fix it yourself.
